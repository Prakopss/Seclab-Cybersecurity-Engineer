Module 6: Network Sniffing (Wireshark) & MITM (Burp Suite)

Praktik perbandingan keamanan lalu lintas jaringan pada protokol HTTP Plaintext (Port 80) vs HTTPS Enkripsi (Port 443).

Network Security
Port 80: HTTP Plaintext
Insecure

Pada port 80, semua paket data (termasuk password dan token otentikasi) dikirim dalam bentuk teks mentah tanpa enkripsi.

Tujuan Praktik Wireshark:
Peserta mengamati adapter loopback/ethernet menggunakan Wireshark, lalu melakukan filter http.request.method == "POST" untuk membaca kredensial pengguna yang disubmit pada form di bawah.
Form Percobaan Pengiriman Plaintext:
Port 443: HTTPS (Self-Signed SSL)
Encrypted

Pada port 443, seluruh lalu lintas dienkripsi menggunakan TLS. Lab ini menggunakan sertifikat mandiri (self-signed) yang dibuat otomatis oleh Docker.

Tujuan Praktik Burp Suite:
Peserta mengonfigurasi proxy browser ke Burp Suite (127.0.0.1:8080) dan mengimpor Burp CA Certificate (PortSwigger CA) agar browser dapat melakukan inspeksi Man-in-the-Middle (MITM) tanpa TLS warning.

Akses server via protokol aman:

Buka https://localhost:443 di Tab Baru * Catatan: Browser akan menampilkan peringatan keamanan (Self-Signed). Ini normal dan merupakan bagian dari latihan!
SOP Praktik 1: Wireshark Sniffing (Port 80)
  1. Buka aplikasi Wireshark di komputer Anda.
  2. Pilih interface penangkapan:
    • Jika menggunakan Docker / Host lokal: pilih Adapter for loopback traffic capture atau vEthernet (DockerNAT/WSL).
    • Jika diakses melalui LAN mentoring: pilih interface Ethernet atau Wi-Fi.
  3. Ketik display filter di bagian atas: http.request.method == "POST"
  4. Submit form kredensial pada kolom Port 80 di sebelah atas halaman ini.
  5. Perhatikan paket HTTP POST yang muncul di Wireshark. Klik kanan paket > Follow > TCP Stream.
  6. Hasil: Peserta akan melihat kredensial username dan password secara telanjang tanpa enkripsi!
SOP Praktik 2: Burp Suite MITM & CA Setup (Port 443)
  1. Jalankan Burp Suite Community Edition. Buka tab Proxy > Intercept dan pastikan status Intercept is on.
  2. Buka browser bawaan Burp (klik Open Browser di tab Proxy) ATAU konfigurasikan ekstensi FoxyProxy ke 127.0.0.1:8080.
  3. Jika menggunakan browser eksternal: Buka http://burp, klik CA Certificate di pojok kanan atas untuk mengunduh cacert.der, lalu impor ke sertifikat browser (Trust as Root Authority).
  4. Akses URL https://localhost:443/sqli melalui browser yang telah ber-proxy.
  5. Burp Suite akan menangkap request HTTPS secara realtime sebelum dikirim ke server.
  6. Hasil: Peserta memahami cara kerja dekripsi SSL/TLS inspeksi proksi pada audit penetrasi aplikasi web.
