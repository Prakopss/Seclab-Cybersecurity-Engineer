Modul 7: Unrestricted File Upload High Risk
Tujuan Pembelajaran:
  • Memahami risiko keamanan jika sistem tidak memvalidasi ekstensi, tipe MIME, dan konten file yang diunggah pengguna.
  • Vektor 1 (Stored XSS via SVG/HTML): Mengunggah file .html atau .svg yang berisi script JavaScript. Saat file dibuka oleh pengguna lain, script dieksekusi di browser korban.
  • Vektor 2 (Web Shell / Script Execution): Mengunggah script eksekusi jika direktori upload mengizinkan eksekusi server-side.
  • Vektor 3 (Bypass Blacklist): Jika server hanya memblokir .php, peserta dapat menguji ekstensi alternatif seperti .phtml, .html, atau manipulasi ekstensi ganda.
