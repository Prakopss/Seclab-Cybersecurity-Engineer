Module 3: Local File Inclusion (LFI)

Celah pembacaan file lokal server melalui eksploitasi Path Traversal pada parameter URL.

OWASP Top 10: A01:2021-Broken Access Control
Dokumentasi & Policy Viewer

Aplikasi menggunakan parameter ?file= untuk memuat file teks dokumentasi dari disk server.

Target Lab untuk Peserta:
  1. Membaca Flag Rahasia: Coba parameter file=flag.txt atau file=../sensitive_files/flag.txt
  2. Membaca Backup Config: Coba file=server_config.bak
  3. Membaca Source Code: Coba file=../app.py atau file=../init_db.py
  4. Membaca File Sistem OS (Docker/Linux): Coba file=/etc/passwd atau file=../../../../../../etc/passwd
