Vulnerable Web Application Lab

Platform simulasi eksploitasi web lokal untuk peserta mentoring Fast Track Cyber Security (4 Minggu).

Lab Environment: Active
Module 1 SQLi
SQL Injection

Pelajari bagaimana input pengguna yang tidak disanitasi dapat memanipulasi logika query SQL di backend.

  • Authentication Bypass (Login admin tanpa password)
  • UNION-Based SQLi (Mengekstraksi data kartu kredit nasabah)
  • WAF case-sensitivity bypass
Masuk Lab SQLi
Module 2 XSS
Cross-Site Scripting

Injeksi payload JavaScript ke dalam browser korban melalui form pencarian dan papan pesan/komentar.

  • Reflected XSS (Eksekusi script via parameter URL)
  • Stored XSS (Penyimpanan script berbahaya di database)
  • Cookie/Session stealing demonstration
Masuk Lab XSS
Module 3 LFI
Local File Inclusion

Manipulasi parameter file loader untuk membaca file sensitif di sistem operasi server via Path Traversal.

  • Directory Traversal (../../)
  • Membaca kode sumber backend (app.py)
  • Mengekstraksi file rahasia server (flag.txt)
Masuk Lab LFI
Module 4 RCE
Command Injection

Memanfaatkan fungsi diagnostik jaringan server (ping util) untuk mengeksekusi perintah shell sistem (RCE).

  • Command chaining (;, &&, |)
  • Reconnaissance server (whoami, id, dir)
  • Bypass filter karakter khusus
Masuk Lab RCE
Module 5 Filter Evasion
Filter & WAF Bypass

Eksplorasi kelemahan mekanisme sanitasi input dan blacklist regex yang tidak komprehensif.

  • Case-sensitivity bypass (<sCrIpt>)
  • Non-recursive sanitization (<scr<script>ipt>)
  • Alternative execution vector (<img onerror>)
Masuk Lab Filter Bypass
Module 6 Wireshark & Burp
Network & SSL Lab

Praktik analisis paket jaringan pada protokol plaintext (Port 80 HTTP) vs terenkripsi (Port 443 HTTPS).

  • Wireshark sniffing: Tangkap password plaintext di HTTP
  • Burp Suite Interception pada port 443 HTTPS
  • Instalasi CA Certificate (cacert.der) untuk MITM
Masuk Lab Network
Module 7 Upload
Unrestricted File Upload

Eksploitasi fitur upload tanpa validasi ekstensi dan tipe file untuk mengunggah script HTML/SVG/Web Shell.

  • Stored XSS via file SVG / HTML upload
  • Eksekusi script / file attachment langsung
  • Bypass blacklist ekstensi sederhana (.php)
Masuk Lab File Upload
Module 8 Recon & Open Dir
Recon & Directory Listing

Teknik reconnaissance web untuk menemukan direktori tersembunyi via robots.txt dan kebocoran backup database.

  • Inspeksi /robots.txt menemukan endpoint rahasia
  • Open Directory /backup/ membocorkan database SQL
  • Ekstraksi kredensial developer & config backup
Open Dir robots.txt
Petunjuk Cepat Mentor & Peserta
Mode Docker

Jalankan perintah docker-compose up -d --build untuk mengaktifkan port 80 (HTTP) dan port 443 (HTTPS) secara bersamaan.

Mode Standalone Python

Jalankan python init_db.py lalu python app.py untuk menjalankan lab langsung di http://localhost:5000.

Reset Status Lab

Jika database terhapus atau tercemar payload XSS berlebih, klik tombol Reset DB di pojok kanan atas untuk memulihkan state awal.
